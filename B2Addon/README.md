# B2 TikTok Zombie Pack

Add-on propio para Minecraft Bedrock 1.26.10.

## Funcionamiento

`TikTok LIVE`

## Compatibilidad

- Minecraft Bedrock 1.26.10+
- `@minecraft/server` 2.6.0
- Diseñado para trabajar con el puente B2

## Próximo paso

Empaquetar `B2Pack` como `.Pack` para instalarlo directamente en Android.
